# Related work

The current primary-source index and focused novelty assessment are in
[REFERENCES.md](REFERENCES.md). The discussion in [PAPER.md](PAPER.md) distinguishes
adaptive exact predicates, IO-aware exact attention, speculative decoding,
local quantization certificates and typed attention-memory contracts.

StateCut v0.2's candidate contribution is the direct count/first-moment/range
residual predicate combined with hierarchical refinement and complete
persistent-write acceptance. Runtime certification itself is not claimed as
new. No first-in-literature result, universal sublinear guarantee or pretrained
speedup is asserted. The original review is preserved in
[archive/RELATED_WORK-v0.1.0.md](archive/RELATED_WORK-v0.1.0.md).
